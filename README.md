# כושר שווה כסף

מסך אחד לילדים: בוחרים כמה שקלים רוצים, לוחצים על תרגילים, ומגיעים ליעד.

Live: https://vbuchatsky-source.github.io/kids-fitness-money/

- למעלה: כמה כסף? אפשר להקליד, או ללחוץ ‎+10 / ‎+20 / ‎+50 / ‎+100 (מצטבר). יש גם איפוס.
- שורת קיצור: מעורב, רק בטן, ידיים, רגליים ובטן — מחלקת את היעד בין התרגילים.
- חמישה כרטיסים גדולים. לחיצה מוסיפה ₪1 לתרגיל. כפתור − בפינה מוריד שקל.
- למטה, תמיד: כמה נבחר מול היעד.

תעריף ברירת מחדל (גלגל שיניים): מתח 8, שכיבות שמיכה 12, סקווטים 20, כפיפות בטן 20, גלגלת בטן 12. נשמר בדפדפן.
