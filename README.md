# כושר שווה כסף

אפליקציה פשוטה: מזינים כמה שקלים רוצים להרוויח, ומיד רואים כמה תרגילים צריך.

Live: https://vbuchatsky-source.github.io/kids-fitness-money/

- יעד בשקלים: הקלדה, או כפתורים 10 / 20 / 50 / 100 שמצטברים, ואיפוס.
- המלצות מיידיות: כל תרגיל בנפרד, וקומבינציות מוכנות. לחיצה על כרטיס ממלאת את הקומבינציה למטה.
- קומבינציה משלי: פלוס/מינוס לכל תרגיל, עם סה״כ מול היעד.
- בהגדרות (גלגל שיניים) אפשר לשנות כמה חזרות שוות שקל אחד.

## תעריף ברירת מחדל

| תרגיל          | חזרות עבור 1 ₪ |
|----------------|----------------|
| מתח            | 8              |
| שכיבות שמיכה   | 12             |
| סקווטים        | 20             |
| כפיפות בטן     | 20             |
| גלגלת בטן      | 12             |

התעריפים נשמרים ב-localStorage בדפדפן. אין שרת.
