# כושר שווה כסף

אפליקציית כושר לילדים: אדם וטום מרוויחים שקלים על תרגילים.

Live: https://vbuchatsky-source.github.io/kids-fitness-money/

## איך זה עובד

- בוחרים ילד (אדם או טום) ומזינים יעד בשקלים.
- האפליקציה מציגה אפשרויות: כל תרגיל בנפרד, וקומבינציות מוכנות (מעורב, בטן, פלג עליון ועוד).
- אפשר לבנות קומבינציה אישית עם פלוס/מינוס ומחוונים, לפי בלוקים של 1 ₪, ולראות אם הגיעו ליעד.
- באימון מסמנים סטים. בסיום הסכום נכנס ליתרה.
- להורה: כפתור «שולם — איפוס יתרה», והגדרת כמה חזרות שוות שקל.

## תעריף ברירת מחדל

| תרגיל          | חזרות עבור 1 ₪ |
|----------------|----------------|
| מתח            | 8              |
| שכיבות שמיכה   | 12             |
| סקווטים        | 20             |
| כפיפות בטן     | 20             |
| גלגלת בטן      | 12             |

הכל נשמר ב-localStorage בדפדפן. אין שרת.
